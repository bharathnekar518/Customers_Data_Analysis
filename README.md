# Customers_Data_Analysis
Data Analytics Project 
Overview

This project demonstrates an end-to-end data analytics workflow using Python, SQL, and Power BI.
The objective of the project is to collect, clean, analyze, and visualize data to generate meaningful business insights and present them through dashboards and reports.

The project covers:

Data loading and preprocessing using Python
Exploratory Data Analysis (EDA)
Data cleaning and transformation
SQL querying using PostgreSQL/MySQL/SQL Server
Interactive dashboard creation in Power BI
Report and presentation preparation using Gamma
Dataset

The dataset used in this project contains structured business/sales/customer-related information.

Dataset Features
Numerical and categorical variables
Missing values and duplicates
Transactional/business insights
Source
Public Dataset / Kaggle / Internal Dataset
